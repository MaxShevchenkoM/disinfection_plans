# План клініки

Інтерактивний план приміщень. Дані зберігаються в Supabase (проєкт `zvirpolis-plan`).

| Середовище | Гілка | Адреса | Таблиця |
|---|---|---|---|
| Прод | `main` | `/` | `plan_prod` |
| Препрод | `preprod` | `/preprod/` | `plan_preprod` |

## Як вносити зміни
1. Зміни в коді — лише в гілку `preprod`. Після `./deploy.sh` вони з'являються на `/preprod/` з тестовими даними.
2. Перевірили — зливаєте `preprod` у `main`.
4. Публікація: `./deploy.sh` збирає обидві гілки в `gh-pages` (Settings → Pages → Deploy from a branch → `gh-pages` / root).
3. Дані проду ніколи не змінюються препродом. На препроді є кнопка «Скопіювати дані з проду».

## Доступ
- Переглядати може кожен із посиланням.
- Редагувати можуть лише адреси з таблиці `editors` після входу за посиланням з пошти.
- Кожне збереження кладе попередню версію в `plan_history`.
